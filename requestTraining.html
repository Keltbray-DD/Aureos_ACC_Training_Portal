What's covered at each level

Level 1 Training

  • Log in and access your project with ease
  • Navigate Forma modules confidently
  • Find, Share and View Files
  • Upload files using the correct process
  • Manage Project Emails
  • Manage Notifications

Level 2A Training

  • Use approval workflows (OCRA) for document reviews
  • Meet ISO 19650 compliance standards
  • Collaborate digitally with mark-ups and comments
  • Compare file versions

Level 2B Training

  • Manage RFIs, Issues and Forms in Forma Build
  • Set up Meetings and add Photos
  • Use Desktop Connector for complex file management
  • Apply Aureos naming conventions
  • Understand structured information management

All users that require Level 2 training also need to complete Level 1 first
